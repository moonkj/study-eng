# ADR 001: 로컬 저장은 shared_preferences + JSON으로 시작

- 상태: 채택 (2026-11-22)

## 배경
레벨, 하루 진행 상황, 학습 기록(날짜별), 복습(SRS) 카드를 앱 재시작 후에도 유지해야 한다.
계획 문서에는 Drift(SQLite)를 적어 두었다.

## 결정
`shared_preferences`에 전체 상태를 JSON 한 덩어리(`todaye.v1`)로 저장한다.
저장소는 `AppStore` 인터페이스(`lib/data/store.dart`) 뒤에 둔다.

## 이유
- 개인용 앱이라 데이터가 작다 (하루 기록 1개 + 카드 수백 개 수준).
- 코드 생성(build_runner)이 필요 없고, 웹 미리보기에서도 추가 설정 없이 동작한다.
- 인터페이스로 분리해 두어 나중에 Drift로 바꿔도 화면·로직 코드는 그대로다.

## 다시 검토할 때
- 카드가 수천 개를 넘어 저장이 눈에 띄게 느려질 때
- 단어장 검색·통계처럼 쿼리가 필요한 기능을 넣을 때
