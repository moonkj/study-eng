# 레벨 맞춤 학습 시스템

## 1. 레벨 체계
- CEFR A1 ~ C1, 각 단계를 .1 ~ .3 세부 단계로 나눔 (예: B1.2) → 총 15단계
- 내부적으로는 0~1500 레벨 점수(100점 = 1세부 단계)로 관리
- 영역 4개를 따로 추적: 어휘 · 문장 구성 · 듣기 · 말하기

## 2. 첫 진단 (적응형, 12문항, 약 4분)
- A2 문항으로 시작 → 맞히면 한 단계 위, 틀리면 한 단계 아래 문항
- 문항 유형을 섞어 영역별 점수 산출: 빈칸 완성(문장), 뜻 고르기(어휘), 듣고 고르기(듣기), 따라 말하기(말하기)
- "잘 모르겠어요" 버튼으로 찍기 방지 (오답과 같게 처리하되 추정 정확도 향상)
- 결과 화면에서 직접 레벨 조정 가능

## 3. 매일 자동 보정
| 신호 | 반영 |
|---|---|
| 퀴즈 정답률 | 가장 큰 비중. 목표 범위 70~85% |
| 단어 카드 "알아요/헷갈려요/몰라요" | 어휘 점수 + 복습 간격(7일/3일/1일) |
| 표현 "이미 알아요/처음 봐요" | 너무 쉬운 표현이 많으면 난이도 상향 |
| 말하기 일치도 | 말하기 점수 |

- 정답률 > 85% 이틀 연속 → 다음 날 콘텐츠 난이도 +1 세부 단계
- 정답률 < 65% → 난이도 -1, 복습 비중 증가
- 가장 약한 영역은 다음 날 분량 비중을 높임 (예: 말하기 문장 10 → 12)
- 조정 내역은 완료 화면과 기록 탭에 "왜 바뀌었는지" 함께 표시

## 4. 콘텐츠 생성
개인용 앱이므로 매일 내 레벨 점수 + 약한 영역 + 최근 30일 학습 내역(중복 방지) + 복습 대상을 Claude에 넘겨 **나만을 위한 오늘의 팩**을 생성한다.
