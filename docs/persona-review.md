## 이번에 반영한 것

### 버그·안정성 (3명 이상 공통 지적 우선)
- 자정을 넘기거나 다음 날 앱으로 돌아오면 오늘로 새로 고침 (앱 복귀 감지 + 자정 타이머)
- 캐시된 팩이 깨져 있으면 버리고 기본 팩으로 시작, 미리 받은 팩도 검증 후 저장
- 팩 요청이 겹치면 최신 요청만 반영 (중복 비용 방지), 재진단 시 미리 받은 팩 폐기
- 기본 팩으로 먼저 시작해도 배운 항목에 등록
- 저장 데이터는 섹션별로 읽어 일부만 깨져도 나머지는 살림, 백업에 시각 기록
- 앱을 열 때 알림 권한을 다시 묻지 않음, 권한이 꺼졌으면 설정에 표시
- 서버: SDK 자동 재시도 끔, 시도당 시간 제한 단축, 앱 제한 시간 > 서버 제한 시간

### 학습 효과
- 실제 복습 세션 추가: 오늘 복습할 카드(최대 20장)를 영어 → 뜻 떠올리기 → 자가 평가 (Claude 호출 없음)
- 같은 날 다시 맞혀도 복습 단계를 올리지 않음, 틀리면 처음이 아니라 2단계만 내려감
- 난이도 목표 하한 0.70 로 정정, 퀴즈로 듣기 점수를 올리지 않음, 출석 보너스 제거
- 서버 프롬프트·검사 강화: 한국인 간섭 실수형 오답(확실히 틀린 문장), 미국식 IPA·강세 표시 한글 발음,
  축약형 구어체, 따라 말하기/퀴즈 문장은 예문과 다르게, 같은 품사 최대 4개
- 샘플 콘텐츠 교정 (오답, in time 해설, IPA, 어색한 예문, 진단 문항)
- 말하기 채점에서 축약형(I'll ↔ I will 등) 동일 처리

### 사용 흐름
- 따라 말하기에 "소리 내기 어려워요" 모드: 듣고 속으로 따라 한 뒤 넘어가기 (점수 평균에서 제외)
- 표현 화면 '말해보기'는 지금 표현의 예문만 따라 말하는 시트로
- 맞춤 팩을 기다리는 동안 "기다리지 않고 기본 학습으로 시작" 버튼
- 진단 건너뛰기 시 한 가지 질문으로 A2 / B1 선택
- 루틴을 끝낸 홈은 "오늘 완료" 카드, 첫 완료 때 아침 알림 시각 제안
- 연속 학습일 칩: 오늘 완료 / 오늘 하면 N+1일 / 저녁인데 아직이면 강조, 최고 연속 기록 표시

### 접근성·UI
- 정답/오답, 말하기 점수를 스크린리더가 읽어 줌 (live region)
- 다르게 들린 단어는 두꺼운 밑줄 + 아이콘 + 스크린리더 라벨(색만으로 구분하지 않음), 퀴즈 진행 칸 라벨·오답 칸 두께 구분, 흐린 보기 대비 개선, 선택 칩 44pt, 달력 학습일 점 표시
- 큰 글씨에서 넘치던 고정 높이를 최소 높이로
- 터치 효과 InkRipple, 학습 화면 전환 페이드

### iPad
- 폭 600 이상: 왼쪽 세로 내비게이션 (1024 이상은 글자 펼침)
- 학습·레벨 화면은 680 폭으로 가운데, 탭 화면은 읽기 좋은 폭
- iPad 가로: 홈 2단 (오늘의 표현·루틴 / 레벨·복습 요약)
- 하드웨어 키보드 단축키: 단어(Space 뜻, 1·2·3 평가), 퀴즈(1~4 선택, Enter 다음), 말하기(Space 마이크, S 천천히, Enter 다음), 표현(←·→), Esc 닫기
- iPhone 은 세로 고정, iPad 는 4방향 + Split View / Slide Over
